# GitHub Pages Information Architecture

This directory documents the intended site structure. The demo publishes from `docs/`, while this `site/` folder acts as the wireframe map for future generated or themed Pages output.

```text
site/
├── index.md
├── accounts/
│   ├── service-hosting-account-a.md
│   ├── service-hosting-account-b.md
│   └── data-analysis-account.md
├── services/
│   ├── service-a.md
│   └── service-b.md
└── shared/
    ├── observability.md
    └── update-model.md
```

## User Journey

```text
GitHub Pages Home
  -> Account Overview
  -> Account A page
  -> Network/Resource diagram
  -> Service communication/data flow page
  -> Links to GitHub repo, CDK repo, dashboard, runbook, and docs
```
